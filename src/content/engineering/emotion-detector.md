# Wireless Emotion Detector

This project integrates hardware and software to capture a live wireless video feed and process it through a computer vision pipeline to detect facial expressions and classify human emotions in real-time.

## Project Overview
- Real-time facial recognition and feature extraction.
- Emotion classification using trained models.
- Wireless camera streaming integration for remote monitoring.
