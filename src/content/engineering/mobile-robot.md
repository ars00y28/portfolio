# SPRO1 Mobile Robot

This project represents a comprehensive mechatronics engineering challenge: designing, building, and programming an autonomous mobile robot from scratch. The system combines mechanical chassis design, electrical power routing, and embedded C++ control systems.

**View the full source code on my GitHub:** [SPRO1-Mobile-Robot](https://github.com/ars00y28/SPRO1-Mobile-Robot)

## Technical Highlights
- **Hardware:** Custom chassis, motor drivers, and sensor arrays (ultrasonic, IR).
- **Control Systems:** PID controllers implemented for smooth and accurate motor actuation.
- **Pathfinding:** Obstacle avoidance and reactive navigation routines.
